# Import ponctuel de l’historique des mouvements

Cette branche temporaire contient l’archive Git vérifiée de 144 étapes reconstituées à partir de 31 snapshots disponibles. Les dates d’août et septembre 2026 sont celles demandées par le propriétaire ; les horaires sont reconstitués.

L’action ne pousse que la nouvelle branche `history/mouvements-aout-septembre-2026`, sans force et sans modification de `main`. Le manifeste fixe son SHA, les jours autorisés et le SHA-256 de l’archive. Le workflow et ces fichiers restent sur cette branche temporaire.
