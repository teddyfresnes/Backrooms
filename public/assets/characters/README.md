# Character assets

`assets-manifest.json` est la source de vérité du configurateur.

- `hair/makehuman/` : 60 coiffures MHCLO réelles ;
- `clothes/makehuman/tops/` : 42 hauts MHCLO réels ;
- `clothes/makehuman/bottoms/` : 17 bas MHCLO réels ;
- `clothes/makehuman/shoes/` : 23 paires de chaussures MHCLO réelles ;
- `hair/HAIR_CREDITS.md` / `.json` et `clothes/makehuman/CLOTHING_CREDITS.md` / `.json` : licences et attributions ;
- `accessories/` : accessoires encore utilisés par le configurateur.

Tous les proxies MHCLO sont ajustés sur HM08 et suivent les morphs du personnage. Les textures intégrées au kit sont des copies WebP optimisées pour le runtime ; les archives source fournies par l’utilisateur restent inchangées.
